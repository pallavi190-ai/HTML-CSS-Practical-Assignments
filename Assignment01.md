# Question 1 - 
<h1>What Happens When We Type A URL</h1>

When you type a URL, your browser checks its local cache or asks a Domain Name System (DNS) server to translate the website name into a numerical IP address, opens a secure TCP/TLS connection with the server, sends an HTTP request for the webpage, and receives code (HTML, CSS, and JavaScript) that it parses and renders into the visible page on your screen.
