# Terminal Navigation Practice Sheet

## Objective
To practice basic terminal navigation commands in VS Code.

## Commands and Their Uses

1. `pwd` - Shows the current directory.
2. `ls` - Displays files and folders.
3. `mkdir [Folder]` - Creates a new folder.
4. `cd Practice` - Opens the Practice folder.
5. `cd ..` - Moves back one folder.
6. `cls` - Clears the terminal screen.

## Practice Commands

```bash
pwd
ls
mkdir Practice
cd Practice
cd ..
cls
```

## Conclusion
Learned how to navigate folders, create a directory, and move lines using terminal commands.
